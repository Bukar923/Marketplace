Target Users: 
• Farmers (easy product management, order tracking, earnings) 
• Buyers (search fresh produce, compare prices, secure payment)

# Marketplace

Marketplace is a mobile-first UI/UX prototype for a digital farm-to-market experience. It connects farmers directly with buyers through a clean, modern interface that supports product discovery, purchasing, and order management.

## Project overview
This app is designed for two main user groups:

- Farmers who want to list products, manage orders, track earnings, and update their store.
- Buyers who want to browse fresh produce, search by category, compare items, add products to cart, and complete checkout.

## Core features
- Onboarding, login, and sign-up flows
- Buyer experience: home, categories, search, product details, cart, checkout, payment success, order tracking, chat, notifications, and profile
- Farmer experience: dashboard, add product, manage orders, earnings, and settings
- Polished, nature-inspired interface built as an interactive case study

## Tech stack
- React 19
- TypeScript
- Vite 8
- Tailwind CSS v4
- Recharts

## Getting started
1. Install dependencies with `pnpm install`
2. Start the development server with `pnpm dev`
3. Open the app at `http://localhost:8443/`

## Project purpose
The goal of this project is to showcase a practical marketplace experience that simplifies agricultural commerce while keeping the user experience intuitive and visually engaging.
